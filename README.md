# 🚀 I2PxO2CUBE Project Archive
> **상상을 현실로 만드는 게임 개발 아카이브에 오신 것을 환영합니다!**

본 저장소는 홍익대학교 세종캠퍼스 게임개발 동아리 **I2PxO2CUBE** 부원들의 소중한 프로젝트를 기록하고 전시하는 공간입니다. 아래 가이드라인에 맞춰 결과물을 제출해 주세요.

---

## 📋 프로젝트 제출 체크리스트
부원들은 프로젝트 완료 후 아래 항목들을 정리하여 운영진에게 제출해야 합니다.

### 1️⃣ 기본 정보 (Text Data)
| 항목 | 필드명 | 설명 | 비고 |
| :--- | :---: | :--- | :--- |
| **팀 정보** | `team` | 개발을 진행한 팀 이름 | |
| **게임 타이틀** | `title` | 프로젝트 공식 명칭 | |
| **한 줄 소개** | `desc` | 리스트 페이지에 노출될 요약 문구 | |
| **상세 내용** | `detail_desc` | 세계관, 특징 등 상세 설명 | 상세페이지용 |
| **진행 연도** | `year` | 프로젝트 진행 시기 (예: 2024, 2025) | 필터링용 |
| **개발진** | `leader`, `members` | 팀장 및 팀원별 이름과 역할 분담 | |

### 2️⃣ 이미지 규격 (Media Assets)
**⚠️ 주의: 모든 이미지는 아래 비율을 엄격히 준수해야 레이아웃이 깨지지 않습니다.**

| 이미지 종류 | 권장 해상도 | 비율 | 용도 |
| :--- | :---: | :---: | :--- |
| **메인 배너** | `1920 x 1080` | **16:9** | 상세페이지 상단 메인 비주얼 |
| **대표 아이콘** | `512 x 512` | **1:1** | 타이틀 옆 및 리스트용 아이콘 |
| **스크린샷** | `1280 x 720` | **16:9** | 인게임 갤러리 (최소 2장 ~ 최대 6장) |

> **💡 Pro Tip**: 모든 이미지는 **`.webp`** 포맷으로 변환하여 제출하면 사이트 로딩 속도가 획기적으로 빨라집니다!

## 📦 제출 및 관리 가이드

### 🎮 게임 빌드 및 동영상
* **게임 빌드**: 실행 가능한 전체 파일을 압축하여 전달해 주세요. (대용량은 Google Drive 링크 권장)
* **유튜브 링크**: 플레이 영상이나 트레일러가 있다면 YouTube 링크를 제출해 주세요.

### 👤 익명성 요청 (Anonymity)
* 개인정보 보호를 위해 실명 노출을 원치 않는 부원은 **익명 처리**를 요청할 수 있습니다.
* **예시**: `홍길동` ➔ `홍*동` 또는 별칭(Nickname) 사용 희망 시 사전에 말씀해 주세요.

---

## 🛠 관리자 업데이트 방법
1. 전달받은 리소스를 `images/` 하위 폴더에 추가합니다.
2. `games.json` 파일의 배열에 새로운 게임 데이터를 추가합니다.
3. `id` 값은 영어 대소문자만 사용하여 중복되지 않게 설정합니다.
