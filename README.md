# I2PxO2CUBE

사용법 : 데이터 추가는 Json을 수정하면 됩니다.
대부분의 경우 HTML, CSS, JS 는 건들지 않아도 되도록 설계 했습니다.
🚀 프로젝트 제출 가이드 (Project Submission Guide)이 아카이브는 I2PxO2CUBE 부원들의 소중한 결과물을 기록하는 공간입니다. 원활한 웹사이트 업데이트를 위해 모든 개발 팀은 아래 규격에 맞춰 자료를 제출해 주세요.📝 1. 프로젝트 정보 (Information)games.json에 등록될 기본 정보입니다. 모든 텍스트는 최종 검수를 마친 상태로 제출해 주세요.항목상세 내용비고팀 이름개발을 진행한 팀 명칭게임 이름프로젝트 공식 타이틀팀원 구성이름 및 담당 역할 (예: 김철수-기획, 이영희-프로그래밍)익명 요청 가능 (아래 참고)한 줄 소개웹 리스트에 표시될 짧은 문구상세 소개게임 세계관, 특징 등 상세 설명상세페이지용출시일202X년 X월 또는 202X년 예정플랫폼PC, Mobile, Web, VR 등🎨 2. 이미지 리소스 (Media)웹사이트의 시각적 완성도를 위해 권장 해상도와 비율을 엄격히 준수해 주세요.💡 중요: 모든 이미지는 가급적 WebP 포맷으로 변환하여 제출하는 것을 권장합니다. (변환이 어려울 경우 고화질 PNG/JPG 제출)게임 메인 배너 (1920x1080 / 16:9): 상세페이지 상단에 사용되는 핵심 이미지입니다.게임 대표 아이콘 (512x512 / 1:1): 리스트 및 상세페이지 타이틀 옆에 노출됩니다.인게임 스크린샷 (1280x720 / 16:9): 최소 2장 ~ 최대 6장을 제출해 주세요.📦 3. 빌드 및 동영상 (Build & Video)게임 빌드: 실행 가능한 전체 압축파일을 제출합니다. (용량이 클 경우 드라이브 링크로 대체)영상 (선택): 트레일러나 플레이 영상이 있다면 YouTube에 업로드 후 링크를 공유해 주세요.👤 4. 개인정보 보호 (Anonymity)웹사이트 내에 본인의 실명이 노출되기를 원하지 않는 경우, 아래와 같이 마스킹 처리를 요청할 수 있습니다.요청 예시: 김성현 → 김*현 혹은 별명(Nickname)으로 대체 요청🛠 제출 방법위 내용을 포함한 폴더를 생성합니다. (폴더명: YYYY_게임이름)담당 관리자(김태현)에게 전달하거나, 권한이 있는 경우 직접 images/ 폴더에 리소스를 추가하고 games.json을 업데이트합니다.
